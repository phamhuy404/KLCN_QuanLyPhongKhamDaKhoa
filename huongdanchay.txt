HƯỚNG DẪN CÀI ĐẶT VÀ KHỞI CHẠY HỆ THỐNG PHÒNG KHÁM ĐA KHOA (CHUẨN KIẾN TRÚC MVC)

I. CÀI ĐẶT MÔI TRƯỜNG VÀ THƯ VIỆN
1. Mở terminal tại thư mục gốc dự án:
pip install -r requirements.txt

II. CHỌN VÀ CẤU HÌNH CƠ SỞ DỮ LIỆU (CHỌN 1 TRONG 3 CƠ CHẾ)
Mở file config.py để chọn loại CSDL bằng cách gán biến DB_ENGINE.

CÁCH 1: DÙNG SQLITE (MẶC ĐỊNH - KHÔNG CẦN CÀI ĐẶT DATABASE SERVER)
1. Trong file config.py, thiết lập:
DB_ENGINE = 'sqlite'
2. File phongkham.db đã được tạo sẵn trong thư mục gốc với cấu trúc bảng đầy đủ và cơ sở dữ liệu trống sạch.

CÁCH 2: DÙNG MICROSOFT SQL SERVER (SSMS)
1. Mở SQL Server Management Studio (SSMS), kết nối vào máy chủ SQL Server.
2. Mở file cosodulieu.sql và nhấn Execute (F5) để khởi tạo CSDL quan_ly_phong_kham và bảng dữ liệu sạch.
3. Trong file config.py, thiết lập:
DB_ENGINE = 'sqlserver'
4. Kiểm tra SQLSERVER_CONFIG trong config.py (mặc định server: localhost, database: quan_ly_phong_kham, Trusted_Connection: yes).

CÁCH 3: DÙNG MYSQL / MARIADB (XAMPP / PHPMYADMIN / DOCKER)
1. Bật MySQL trên XAMPP hoặc MySQL Service.
2. Nhập file cosodulieu_mysql.sql vào MySQL (qua phpMyAdmin hoặc lệnh terminal: mysql -u root < cosodulieu_mysql.sql).
3. Trong file config.py, thiết lập:
DB_ENGINE = 'mysql'
4. Kiểm tra MYSQL_CONFIG trong config.py (user, password, port nếu có thay đổi).

III. KHỞI CHẠY ỨNG DỤNG WEB
1. Chạy lệnh:
python app.py

2. Mở trình duyệt web truy cập địa chỉ:
http://127.0.0.1:5000
